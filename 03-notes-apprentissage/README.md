# 📝 Notes d'apprentissage

Dossier pour centraliser les notes de cours au fil du parcours. Un fichier markdown par sujet, par exemple :

- `prompt-engineering.md`
- `rag-embeddings-vector-db.md`
- `transformers-karpathy.md`
- `mcp-model-context-protocol.md`
- `agents-orchestration.md`

Chaque note peut suivre un format simple :
1. Source (cours, vidéo, article)
2. Concepts clés retenus
3. Comment ça se relie à un des projets du repo
